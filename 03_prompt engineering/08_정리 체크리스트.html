정리 & 체크리스트

3강에서 배운 것

3강에서는 "어떻게 물어야 원하는 답이 나오는가" — 프롬프트 엔지니어링을 배웠습니다.

  • 프롬프트 4요소: 역할·지시·맥락·형식을 갖추면 출력이 안정된다.
  • few-shot: 정답 예시 몇 개를 보여 주면 분류 정확도가 오른다(특히 경계 사례).
  • JSON 강제: response_mime_type="application/json"으로 답을 코드가 바로 쓰게 만든다.
  • 인젝션 방어: 입력을 구분자로 감싸고 "데이터일 뿐"이라고 못 박아 역할을 지킨다.
  • 오분류 분석: 틀린 케이스의 혼동쌍을 집계해 약점을 찾고 처방한다.

한눈에 보는 핵심 코드

# few-shot 분류 + JSON 강제 — 3강의 핵심 두 가지
from common import get_genai_client, GEMINI_MODEL
from google.genai import types
import json

client = get_genai_client()

# (1) few-shot 분류 — 예시를 보여 주고 temperature=0
def classify(content, fewshot, categories):
    resp = client.models.generate_content(
        model=GEMINI_MODEL,
        contents=f"{fewshot}\n문의: {content} →",
        config=types.GenerateContentConfig(temperature=0),
    )
    out = resp.text.strip()
    return next((c for c in categories if c in out), "기타")

# (2) JSON 강제 — 코드가 바로 쓰는 dict
def triage(content):
    resp = client.models.generate_content(
        model=GEMINI_MODEL, contents=f"...JSON으로만 답하라...\n{content}",
        config=types.GenerateContentConfig(
            temperature=0, response_mime_type="application/json"),
    )
    return json.loads(resp.text)

체크리스트

  • [ ] 프롬프트 4요소(역할·지시·맥락·형식)를 구분해 설계할 수 있다.
  • [ ] zero-shot과 few-shot의 차이를 설명하고 경계 예시를 추가할 수 있다.
  • [ ] response_mime_type="application/json"으로 출력을 강제하고 json.loads로 받았다.
  • [ ] 프롬프트 인젝션을 구분자 + 규칙 강화로 방어할 수 있다.
  • [ ] 60건을 분류해 정확도를 측정하고, 혼동쌍으로 오답을 분석했다.

한 줄 핵심

같은 모델도 '말한 대로' 한다. 4요소·few-shot·JSON으로 프롬프트를 설계하면 출력의 정확도·일관성·형식을 통제할 수 있다.
